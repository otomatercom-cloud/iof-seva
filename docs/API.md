# API contract

## Browser → Next.js: `POST /api/volunteer-registration`

Headers: `Content-Type: application/json`, `Idempotency-Key: <16–64 chars [A-Za-z0-9_-]>` (the form generates one per attempt and reuses it on retry), `Origin` must match the site host.

Body (strict allowlist, unknown keys ignored): `first_name*, last_name*, gender (male|female|other), date_of_birth (YYYY-MM-DD), nationality, iqama_number, saudi_city (list in code), mobile*, whatsapp, email*, address, city, region, occupation, organization, qualification, interests[] (codes), other_interest, special_skills, experience, languages, availability[] (weekdays|weekends|emergency), hours_per_month, emergency_name, emergency_relationship, emergency_phone, consent* (boolean true), website (honeypot, must be empty)`.

| Status | Body |
|---|---|
| 200 | `{"ok":true,"reference":"IOF-VOL-00012"}` (reference generated by Odoo) |
| 400 | invalid request / honeypot / bad key |
| 403 | cross-origin |
| 413 | body > 64 KB |
| 422 | `{"ok":false,"error":"validation_error","message":"..","fields":{"email":".."}}` |
| 429 | rate limited, `Retry-After` header |
| 503 | Odoo unreachable/timeout; "your details were not saved" |
| 500 | any other failure, generic message |

## Next.js → Odoo: `POST {ODOO_BASE_URL}/api/iof/volunteer-registration`

`Authorization: Bearer <iof_volunteer_registration.api_token>`, `Idempotency-Key` header, JSON body as above (minus honeypot).

| Status | Meaning |
|---|---|
| 201 | created: `{"ok":true,"reference":"IOF-VOL-…","replayed":false}` |
| 200 | same key replayed: existing reference returned, nothing created |
| 400 | invalid JSON / idempotency key |
| 401 | missing or wrong token |
| 413 | payload too large |
| 422 | `{"ok":false,"error":"validation_error","fields":{..}}` |
| 503 | token not configured |
| 500 | `{"ok":false,"error":"server_error"}` (no internals) |

`GET /api/iof/health` (same Bearer token) → `{"ok":true}`.

Duplicate policy: only an identical `Idempotency-Key` is deduplicated. The same email/mobile in a *different* submission is accepted (families share phones); Odoo shows a "possible duplicate" banner on the record for staff.
